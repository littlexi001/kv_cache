# 证据与 Query 同移 48 token：研究设计

## 研究问题

旧实验中，两跳样例在 47 个 body token 时能正确预测 `basket`。本实验检验：若加入 48 个完全相同的 filler token，但让证据与 Query 一起后移，使两者相对距离严格不变，`basket` 的概率是否仍会显著下降。

## 可证伪假设

- **H1（相对距离主导）**：只拉长证据—Query 距离会降低 `P(basket)`；证据与 Query 同移且相对距离不变时，概率应接近原始样例。
- **H2（绝对前缀/内容状态也重要）**：即使相对距离不变，新增的因果前缀仍会改变证据和 Query 的中间表示，因此概率仍可能变化。

## 三组严格配对条件

1. `original_47`：复用旧实验 `length_47.json` 中完整的 114 个 prompt token。
2. `gap_plus_48`：在旧 body 与 Query 之间插入固定的 48 个 filler token。证据位置不变，Query 后移 48，因此相对距离增加 48。
3. `co_shift_plus_48`：把同一组 48 个 filler token 插在第一条证据链之前。证据与 Query 都后移 48，因此它们的相对距离保持不变。

三组使用同一 Qwen3-8B 权重、同一 prompt 后缀、同一答案和确定性前向。两组加长条件具有相同的总 token 数和相同的新增 token 多重集，只改变新增 token 的插入位置。

## 边界

`co_shift_plus_48` 是数据级干预，不是纯 RoPE 反事实：新增 token 位于证据之前，会通过因果注意力改变证据的内容表示。因此它能检验“相对位置保持是否足以保持输出”，但不能单独证明所有变化都来自或不来自 RoPE。
