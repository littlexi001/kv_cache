# 证据与 Query 同移 48 token：实验结果

## 一句话结论

在这条 47-token 临界样例上，新增 48 token 若把证据—Query 相对距离拉长，正确答案概率从 **45.34%** 降至 **6.52%**；若证据与 Query 一起后移 48 token、相对距离严格不变，概率为 **42.11%**。因此，这次骤降的主要变量确实是证据与 Query 的相对距离，而不是 Query 的绝对位置单独增加 48。

![配对实验结果](../outputs/analysis/relative_fixed_48_shift.png)

## 实验结果

| 条件 | Prompt token | `basket` 到 Query 的距离 | `P(basket)` | 最强错误 token | `P(error)` | 输出 margin | Gold PPL |
|---|---:|---:|---:|---|---:|---:|---:|
| 原始 47 | 114 | 79 | 45.34% | `Let` | 7.64% | +1.781 | 2.206 |
| 只增加相对距离 48 | 162 | 127 | 6.52% | `Let` | 41.22% | -1.844 | 15.334 |
| 证据与 Query 同移 48 | 162 | 79 | 42.11% | `Let` | 17.28% | +0.891 | 2.375 |

同移恢复了“只增加相对距离”造成的 **91.7% 正确答案概率损失**，并使决策重新回到正确一侧。它没有完全恢复原始 margin，说明相对距离不是唯一变量。

## 内部量如何对应输出变化

| 条件 | 四个原子证据的全模型 attention mass | L30--L33 证据 mass | 全模型平均证据 QK | L30--L33 平均证据 QK |
|---|---:|---:|---:|---:|
| 原始 47 | 1.423% | 2.827% | 4.583 | 4.665 |
| 只增加相对距离 48 | 0.917% | 1.900% | 4.087 | 4.198 |
| 证据与 Query 同移 48 | 1.212% | 2.284% | 4.419 | 4.535 |

只拉长相对距离时，证据 QK、证据 attention mass 和输出 margin 同时下降；同移后这些量均向原始条件恢复。最终答案 token `basket` 自身获得的全模型 attention mass 也呈相同方向：**0.602% -> 0.354% -> 0.512%**。

## 如何理解

第一层的直接 RoPE 相对位置项满足

$$
s(t,p)=\frac{1}{\sqrt d}q^\top R_{p-t}k.
$$

同移使 $p$ 与 $t$ 同时加 48，所以 $p-t$ 不变；只在证据之后加 48，则 $p-t$ 改变 48。实验结果与“相对相位变化会压低远程证据 QK”一致。

但同移条件仍从 45.34% 小幅降至 42.11%，margin 从 1.781 降至 0.891。原因是这是数据级干预：48 个新 token 被放在证据之前，会通过因果注意力改变证据 Key/Value 的内容表示，并沿后续层改变 Query。保持 $p-t$ 只能固定显式 RoPE 相位，不能保证 pre-RoPE 的 $q$、$k$ 和 residual 完全不变。

## 结论边界

这是同一条临界样例上的机制对照，能回答该骤降是否主要来自相对距离；它还不能估计这一比例在不同样例、不同 seed 或真实任务上的总体分布。原始逐 head 数据保存在 `outputs/conditions/`，紧凑摘要保存在 `outputs/results.json` 与 `outputs/analysis/summary.csv`。
