# Temporal Representation Fusion: 研究设计

## 研究问题

在已知的单跳长上下文失败边界中，长度 143,424 时模型首 token 正确输出 `nine`，长度 143,488 时转而输出 `newline`。此前把较短长度的中间层表征替换到较长长度上，可以恢复正确输出。

本实验检验一个更弱、也更接近可用方法的命题：不完全替换表征，只把历史 Query 表征与当前 Query 表征融合，能否恢复远程证据检索？如果能，收益究竟来自旧语义状态，还是来自旧的 RoPE 相位？

这里“历史步”定义为：同一问题、同一 Query token，在更短总长度下得到的表征；不是当前序列中向前数某个 token 的表征。`100` 不被当作固定超参数，而只是历史偏移量的一个例子。

由于第 $i$ 个 RoPE 二维对在偏移 $\delta$ 下产生相位差 $\delta\omega_i$，不同频率的周期呈几何尺度分布，不存在对所有层、head 和频率都最优的单一固定间隔。因此先建立对数间隔的历史表征库，再按模型真实 post-RoPE Query 的角度覆盖选择锚点。

## 假设

- H1（历史表征可恢复）：在某个中间层，存在小于 1 的融合比例，使失败样例的 `nine-newline` margin 从负变正。
- H2（相位互补）：保留历史 Query 原生 RoPE 相位的融合，优于把历史 pre-RoPE Query 重新旋转到当前位置后的融合。
- H3（特异性）：历史表征的真实方向优于等范数的随机/相位打乱方向。

## 间隔、锚点数和多级融合

- 候选偏移：在 1–512 token 内采用对数网格，并在已知 64-token 转折附近加密。
- 单锚点：测试已知正确的 64-token 历史点，以及与当前 post-RoPE Query 夹角最大的历史点。
- 多锚点：用最远点采样选 2 个和 4 个相位互补锚点，比较是否比单锚点稳定。
- 多层融合：先找出最佳单层；只有单层有效后，再把最佳两个层串联干预。这样避免把“多历史锚点”和“多网络层”两个因素混在一起。

## 已知正对照

此前 143,424 → 143,488 的精确替换实验中，从 L16 起替换 `residual_in` 可以恢复 `nine`；L20–L23 的恢复最强。因此本轮先扫描 L16、L20、L22、L23、L24，避免在 36 层上盲目搜索。

## 成功与失败的含义

- 若只有融合比例 1 有效：说明“替换”有效，但尚不支持“融合”方法。
- 若残差融合有效，而两种 Query 融合相近：支持历史语义/状态复用，不支持相位互补。
- 若原生相位融合显著优于当前位置相位融合：直接支持相位互补。
- 若相位打乱控制同样有效：恢复可能只是一般扰动或平滑，不是历史相位特异性。

## 边界

第一阶段只验证一个已知失败边界，目的是快速证伪机制。它不能单独证明方法可泛化；若通过，再扩展到多个失败长度、多个 filler seed 和两跳/RULER 数据。
