# 可视化与结果记录

## 实验设置

研究问题是：在 Qwen3-8B 的同一个单跳长上下文失败样例上，历史 Query 表征与当前表征融合，能否恢复远程证据检索；若能，恢复是否来自历史 RoPE 相位。

- 失败目标：总长度 143,488，正确首 token 为 `nine`，当前模型输出 `newline`。
- 历史候选偏移：1、2、4、8、16、32、48、64、96、128、192、256、384、512 tokens。
- 干预层：L20–L24；残差流在 L20、L22、L23 测试。
- 历史锚点数：1、2、4；锚点由 post-RoPE Query cosine distance 的最远点采样选择，不读取答案。
- 融合比例：0.25、0.50、0.75、1.00。
- 三种条件：残差流线性融合；pre-RoPE Query 融合后使用当前位置相位；保留历史原生相位的 post-RoPE Query 融合。
- 硬恢复：`nine-newline` logit margin 大于 0，且首 token 为 `nine`。
- 运行脚本：`src/run_temporal_representation_fusion_8b.py`。
- 合并结果：`outputs/temporal_representation_fusion_20260804_phase_bank_v4_8gpu/merged/`。

本轮共得到 208 个干预点。四个 GPU shard 的未干预 baseline 在概率、margin、QK 和 attention mass 上一致。

## 直接结果

| 条件 | `P(nine)` | `nine-newline` margin | 加权证据 QK | 加权证据 attention mass | 首 token |
|---|---:|---:|---:|---:|---|
| 未干预失败 baseline | 1.745% | -2.750 | 10.001 | 0.477% | `newline` |
| 最佳部分融合：L23 残差，偏移 512，alpha=0.75 | 7.636% | -1.000 | 13.553 | 6.307% | `newline` |
| 唯一硬恢复：L23 残差，偏移 512，alpha=1.00 | 19.558% | +0.125 | 14.633 | 11.058% | `nine` |
| 最佳 current-phase Query 条件：L24，偏移 64，alpha=1.00 | 4.045% | -2.000 | 11.536 | 6.147% | `newline` |
| 最佳 native-phase Query 条件：L24，4 锚点，alpha=1.00 | 5.416% | -1.625 | 11.658 | 6.840% | `newline` |

208 个组合中只有 1 个硬恢复，占 0.48%；它的 `alpha=1` 表示完全使用历史残差，不是当前与历史的真正混合。因此本轮再次证明了“历史状态替换可以救回输出”，但没有证明“部分融合已经足以恢复输出”。

## 融合比例怎样影响 L23

固定使用自动选出的单锚点偏移 512：

| alpha | `P(nine)` | margin | 加权 QK | 加权证据 mass | 输出 |
|---:|---:|---:|---:|---:|---|
| 0.25 | 2.209% | -2.500 | 11.169 | 1.186% | `newline` |
| 0.50 | 3.508% | -2.000 | 12.367 | 2.941% | `newline` |
| 0.75 | 7.636% | -1.000 | 13.553 | 6.307% | `newline` |
| 1.00 | 19.558% | +0.125 | 14.633 | 11.058% | `nine` |

历史残差占比提高时，QK、attention mass、答案概率和输出 margin 同向改善，说明该方向确实携带可恢复的证据信号；但 0.75 到 1.00 之间仍存在尚未精确定位的决策边界。

## 一个锚点还是多个锚点

在唯一接近成功的 L23、`alpha=1` 条件下：

| 锚点 | margin | `P(nine)` | 结果 |
|---|---:|---:|---|
| 偏移 512，一个锚点 | +0.125 | 19.558% | 正确 |
| 偏移 512+64，两个锚点均值 | -0.125 | 17.080% | 错误 |
| 偏移 512+64+256+384，四个锚点均值 | 0.000 | 18.180% | 平局，未严格恢复 |
| 固定偏移 64，一个锚点 | -0.375 | 13.972% | 错误 |

因此，“融合更多历史相位”并不自动更好。不同历史状态做均值会互相抵消；在这个样例上，单个偏移 512 的残差优于 2/4 锚点均值。该结果否定了“只要增加锚点数就能更稳定恢复”的简单版本。

## 历史原生相位是否有额外价值

在 80 个严格配对条件中，native-phase 与 current-phase 使用相同层、相同历史状态、相同锚点数和相同 alpha，只改变历史 Query 是否保留原生 RoPE 相位。

- native-phase 的 margin 平均高 0.166，80 对中 57 对更高；
- 加权证据 QK 平均高 0.038，56 对更高；
- 加权证据 attention mass 平均高 0.110 个百分点，65 对更高；
- 三项同时更好的有 40/80；
- 最大配对 margin 优势为 +0.625，出现在 L22、偏移 512、alpha=0.50。

这说明保留历史相位有小而不稳定的增益，尤其在 L20、L22、L24 更常见；但所有 Query-only 条件仍输出 `newline`。所以本轮只支持“相位可能提供辅助增益”，不支持“相位补偿是恢复能力的主要原因”。

## 当前结论

1. 历史中间表征确实包含当前失败状态丢失的证据信号；L23 的历史残差完全替换可再次恢复 `nine`。
2. 部分融合形成连续的软恢复，但当前粗粒度 alpha 网格中没有部分融合跨过输出边界。
3. 多锚点均值没有优于最佳单锚点，说明不能把不同相位无条件平均。
4. 保留历史原生相位通常比把历史 Query 重新旋转到当前位置略好，但效果不足以单独恢复答案；主要恢复来源仍更像完整的历史残差状态，而不只是 Q 的 RoPE 相位。

## 还不能声称什么

- 尚未逐一测试 14 个偏移作为单锚点，因此不能声称 512 是最优间隔；它只是无监督角度覆盖首先选出的偏移。
- 尚未在 0.75–1.00 之间细扫，不能给出最小有效历史权重。
- 尚未测试两个网络层同时做部分残差融合，不能判断多层弱干预能否替代单层完全替换。
- 尚未运行相位打乱和等范数随机方向控制，因此不能把 native-phase 的小增益完全归因于特定历史相位。
- 当前只有一个失败样例，不能外推到其他 filler、问题或模型。
