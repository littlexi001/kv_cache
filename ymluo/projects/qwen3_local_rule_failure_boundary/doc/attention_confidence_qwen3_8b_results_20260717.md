## 与旧表的口径差异

旧表的 6.284 → 9.276 来自 Qwen3-0.6B、16 个 seed 的均值；本次是 Qwen3-8B、固定 seed 0 的单条链。模型规模与聚合口径都不同，因此本次结果不构成对旧表的复现失败，也不能用单样本替代 16-seed 均值。

本样本从 short 到 64K 时，三个 code span 的 raw mass 有所下降，但它们相对 uniform baseline 的 enrichment 大幅上升。原因是 key 数量增加近 500 倍，而 evidence mass 只下降了小幅比例。由此可见，raw softmax mass 会受到分母长度机械影响，必须与 span 长度 / key 长度的均匀基线一起报告。
