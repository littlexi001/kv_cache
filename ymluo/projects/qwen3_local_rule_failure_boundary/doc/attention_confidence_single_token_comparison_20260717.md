# Qwen3-8B 单-token 证据编码对照实验

日期：2026-07-17

## 实验目的

旧实验使用 `GA89-987` 一类编号，一个编号会被 Qwen3-8B tokenizer
拆成多个 token。本实验只改变编号表示：使用在规则文本和查询文本中均稳定占
一个 token 的不透明汉字编号。模型、seed 0、两跳 clean 链、middle placement、
0–64K 长度范围、500-token 步长和 attention 采集方法全部保持不变。

本次链条为 `佑 → 丝 → 须`，token id 分别为 108395、99691、100360。
四个证据角色 `start_key`、`hop1_result`、`hop2_input`、`hop2_result`
在实际规则文本中的 span 宽度均严格为 1。

## 主要结果

129/129 个长度点全部完成。

| 长度 | 多-token PPL | 多-token / short | 单-token PPL | 单-token / short |
|---:|---:|---:|---:|---:|
| 0 | 6.8058 | 1.000× | 2.4922 | 1.000× |
| 1K | 6.5389 | 0.961× | 1.0310 | 0.414× |
| 8K | 6.5438 | 0.961× | 1.2730 | 0.511× |
| 32K | 5.4723 | 0.804× | 1.1548 | 0.463× |
| 64K | 5.0646 | 0.744× | 3.1246 | 1.254× |

- 多-token：长度与 PPL 的 Pearson 为 **-0.7204**。
- 单-token：长度与 PPL 的 Pearson 为 **+0.4316**，Spearman 为 **+0.8299**。
- 单-token 的第二跳最终结果 attention mass 与长度的 Pearson 为 **-0.8716**。
- 单-token 的两个结果 token 总 attention mass 与 PPL 的 Pearson 为 **-0.5052**。
- attention entropy 与长度的 Pearson 为 **+0.9457**。

因此，去掉编号分词以后，这条样本出现了更符合“长文本信心下降”的内部关系：
长度增加时最终证据 token 的 attention 下降，而答案 PPL 总体上升。旧的
多-token 单样本趋势相反。

## 长文本波动

单-token PPL 并非平滑上升。其均值为 3.6334、中位数为 2.0121，最大值出现在
57K，为 55.2685。40K、52.5K、54K、55.5K、57K、57.5K、58.5K 等位置存在
明显尖峰。这说明本例除了全局退化趋势，还对 filler 截断位置和局部上下文非常敏感；
不能只用 short 与 64K 两个端点判断机制。

## 证据 attention

| 长度 | 第一跳结果 | 第二跳输入 | 最终结果 | entropy |
|---:|---:|---:|---:|---:|
| 0 | 0.012744 | 0.005055 | 0.015928 | 2.9425 |
| 1K | 0.010795 | 0.006072 | 0.025297 | 3.6442 |
| 8K | 0.010990 | 0.004704 | 0.021127 | 4.1996 |
| 32K | 0.011324 | 0.005535 | 0.018824 | 4.8423 |
| 64K | 0.010975 | 0.004498 | 0.011637 | 5.4471 |

64K 时，三个单-token 证据相对 uniform attention 的 enrichment 仍分别达到
703.1×、288.2×、745.6×。因此 raw mass 的下降既包含 softmax 分母增长带来的
机械稀释，也包含证据选择性的变化；报告时需要同时展示 raw mass 和 uniform
enrichment。

## 解释限制

1. 两种模式的绝对 PPL 不能直接横向比较：旧答案包含多个目标 token，新答案只有
   一个目标 token，而且不同 token 的词频先验不同。应比较各模式内部相对 short
   基线的趋势。
2. 单-token 编号虽然消除了分词边界，但汉字 token 仍可能有语义和频率先验。
3. 当前仍是固定 seed 0 的单条链；相关性不能替代多 seed 因果结论。
4. 下一步最有价值的验证是固定多组单-token 编号和 filler，重复多个 seed，检查
   `hop2_result mass ↓ → PPL ↑` 是否稳定复现。
