# 06 — Wider deep high-frequency 0.5× phase

In the deepest third, F0–F15 accumulate phase at half speed:

$$
\phi_{\ell i}(p)=0.5p\omega_i,qquad i<16.
$$

This changes a wider band more conservatively than method 05. The comparison
tests whether the important variable is intervention strength or frequency-band
width. If it has lower PPL damage but weaker retrieval, the extra position
signal helps language modeling but leaves more long-distance phase interference.
