# 迭代记录

## Iteration 1：约 128M 合成预训练筛选

- **猜想：** 深层高频 RoPE 会妨碍远程内容匹配；连续减速可能比硬删除更稳。
- **参数化：** 深层 F0-F7 删除、全层 0.5 倍相位、连续层-频率缩放。
- **操作化：** 四个相同 Qwen-style 小模型从相同初始化开始，在相同在线合成数据上训练 20M token。
- **profiling：** 训练 loss、gradient norm、吞吐、显存、不同长度的答案准确率和 NLL。
- **状态：** 等待远程训练结果。
- **下一不确定性：** 哪个方案能在 4K/8K 改善检索，同时保持 512/1K？

## Iteration 1a：失败的低权重 pilot

- **结果：** 31 号机训练约 5M token 后，整体监督 loss 已降到约 0.22，但 512/1K/2K 的检索准确率仍为 0。
- **失败原因：** 每条序列只有一个检索答案，而结构监督位置约 370 个；检索信号不到总监督的 0.3%。模型主要学会了 filler 和标记格式。
- **解释边界：** 这只否定了原 loss 配比，不能用于比较 PE。
- **更新：** 正式 v2 每条序列使用 4 个查询，答案权重为 64，使检索约占 loss 权重四成；四个 PE 条件从相同初始化重新训练。
