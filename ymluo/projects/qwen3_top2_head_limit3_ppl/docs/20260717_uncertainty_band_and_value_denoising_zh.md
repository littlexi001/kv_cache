# 误差校准 KV 检索与有界 Value 去噪

更新时间：2026-07-17

## 1. 核心问题

PCA64 INT4 可以低成本估计每个 query head 对历史 K 的相关性，但压缩分数存在误差。固定候选预算有两个问题：

1. 简单 query 使用过多候选，浪费精确 QK 计算。
2. 困难 query 的固定候选可能不够，漏掉真实高分 token。

本轮探索的目标是：不训练 router，不使用任务标签，仅根据当前 query/head 的代理分数误差，自动决定需要精排多少候选。

## 2. 误差校准不确定性带

当前主路径如下：

1. 用 PCA64 INT4 索引扫描全部历史 K，得到代理 QK 分数。
2. 均匀抽取约 0.25% 的历史 token，计算精确 QK。
3. 用精确分数与代理分数之差估计当前 query/head 的误差标准差 `sigma`。
4. 找到代理 top2% 的边界分数 `b`。
5. 仅将代理分数不低于 `b - z * sigma` 的 token 送入精确 QK。
6. 从精确候选中选出最终 top2%，再读取对应 V 完成 attention。

`z` 是唯一的风险参数。误差小、边界清晰时，候选带自动变窄；误差大或边界密集时，候选带自动变宽。

这不是任务 router，也不需要训练标签。预算由当前 query/head 的可观测误差直接决定。

## 3. 真实 PPL 结果

32K 体育和医学 window 0：

| 方法 | 体育 PPL | 医学 PPL | 体育候选 | 医学候选 |
|---|---:|---:|---:|---:|
| 固定 c4 | 9.4230 | 10.4340 | 4.00% | 4.00% |
| 固定 c6 | 9.4070 | 10.4217 | 6.00% | 6.00% |
| 不确定性带，z=0.75 | 9.4136 | 10.4307 | 4.00% | 3.93% |
| 不确定性带，z=1.0 | 9.4093 | 10.4245 | 4.91% | 4.81% |

结论：

- `z=0.75` 在与固定 c4 相同或更低的候选量下，两项 PPL 都更低。
- `z=1.0` 用约 4.9% 候选，基本达到固定 c6 的质量。
- 自适应预算的优势已经由真实 PPL 验证，不只来自 attention-mass 代理指标。

## 4. 128K 物理速度

测试对象为单层、单 token attention 子系统，基线是 Full SDPA；索引比例按完整 FP16 K+V 计算。

| 设置 | Attention 加速 | 备注 |
|---|---:|---|
| 随机输入，不确定性带，修复前 | 0.94x | 包含两次非连续历史 K 全量复制 |
| 随机输入，不确定性带，零拷贝后 | 1.97x | 随机分布触发 8% 候选上限 |
| 真实 Q/K replay，z=0.75 | 2.17x | 5 层、体育/医学聚合 |
| 真实 Q/K replay，z=0.75 + bounded V 0.95 | 2.27x | 5 层、体育/医学聚合 |
| 固定 c4 | 2.36x | 5 层、体育/医学聚合 |

PCA64 INT4 持久索引约为完整 FP16 K+V 的 6.77%。

本轮完成的关键工程修复：

- exact sample 和 exact rerank 直接读取包含当前 token 的连续 K；候选索引仍严格限制在历史范围。
- 去掉了每步两次 `1 x 8 x 131072 x 128` 的历史 K 连续化复制。
- 将 sample exact-QK、代理误差和方差估计融合为一个 CUDA kernel。
- 融合误差标准差与原 PyTorch 实现最大绝对误差为 `1.19e-7`，耗时约 0.025 ms。

## 5. 有界 Value 去噪

精确 top2% 分数已经得到后，不一定需要读取其中全部 V。对于 top2 集合中的 `n` 个位置，令归一化前 softmax 权重总和为 `Z`。给定质量下界 `tau_v`，跳过单个权重低于

`(1 - tau_v) * Z / n`

的 V。因为最多跳过 `n` 项，总丢弃权重严格小于 `(1 - tau_v) * Z`，所以保留质量至少为 `tau_v`。

该规则不需要 router，也不需要串行 top-p 前缀扫描。权重按精确分数降序排列，因此可以用二分查找确定保留前缀。

### 5.1 跨主题 PPL

固定 `z=0.75`，仅比较 `tau_v=1.0` 与 `tau_v=0.95`：

| 数据 | 原方法 PPL | bounded V PPL | 相对变化 |
|---|---:|---:|---:|
| 体育 w0 | 9.4136 | 9.3658 | -0.508% |
| 体育 w1 | 2.5885 | 2.5868 | -0.067% |
| 体育 w2 | 23.7987 | 23.6136 | -0.778% |
| 医学 w0 | 10.4307 | 10.3270 | -0.994% |
| 医学 w1 | 7.7392 | 7.7081 | -0.402% |
| 医学 w2 | 8.7090 | 8.6770 | -0.367% |
| 计算机 w0 | 14.3825 | 14.3921 | +0.067% |
| 航天 w0 | 17.1662 | 17.0766 | -0.522% |
| 政治 w0 | 14.9826 | 14.8855 | -0.648% |
| 宗教 w0 | 12.2490 | 12.1819 | -0.547% |

共 9/10 个配对改善，等权几何平均 PPL 改善约 0.477%。候选比例保持不变，说明变化来自 V 聚合，而不是 K 检索路径。

体育和医学 w0 的初步阈值曲线在 `0.90–1.00` 范围内持续改善；目前最低已测值：

| `tau_v` | 体育 PPL | 医学 PPL |
|---:|---:|---:|
| 1.000 | 9.4136 | 10.4307 |
| 0.975 | 9.3943 | 10.3789 |
| 0.950 | 9.3658 | 10.3270 |
| 0.925 | 9.3527 | 10.3039 |
| 0.900 | 9.3416 | 10.2926 |

这提示低权重 V 不只是计算负担，也可能对 next-token prediction 形成噪声。但更低阈值尚未完成独立验证，不能据此确定最终超参。

## 6. 已否定或暂不采用的分支

### 6.1 直接全历史直方图候选

尝试完全去掉固定 overfetch，对全部代理分数直接做两级直方图并压缩不确定性带。

- 正确性：32 个 head 的代理 top2% 全部保留，无 8% 容量溢出。
- 问题：128K 直接选择耗时约 0.586 ms，完整路径仅约 1.68x。

结论：概念更简洁，但当前物理实现不合格，不替换主路径。

### 6.2 串行最短 top-p 前缀

最短前缀能显著减少 V 数量，但 thread 0 串行扫描最多 2622 个权重，真实 replay 速度下降到约 2.05–2.09x。

结论：已用有界阈值和二分查找替代。

### 6.3 增大 PCA 投影维度

PCA96/PCA128 没有稳定恢复固定 overfetch 的质量，同时索引和扫描成本上升。

结论：PCA64 仍是当前较优点。

## 7. 创新边界

不能把“top-p sparse attention”本身作为创新。Twilight 和 Double-P 已经研究了按 attention mass 自适应保留 token：

- [Twilight: Adaptive Attention Sparsity with Hierarchical Top-p Pruning](https://arxiv.org/abs/2502.02770)
- [Double-P: Hierarchical Top-P Sparse Attention for Long-Context LLMs](https://arxiv.org/abs/2602.05191)

当前更有区分度的主线是：

1. 用 PCA64 INT4 建立低成本 per-head 全历史代理分数。
2. 用极少量精确样本在线估计当前 query/head 的代理误差。
3. 用误差尺度构造候选边界不确定性带，而不是固定候选预算、任务规则或训练 router。
4. 只在不确定性带内计算精确 QK。

bounded V 适合作为第二项贡献：它不是主检索创新，而是一个无需训练、具有质量下界、并观察到去噪效应的聚合优化。
