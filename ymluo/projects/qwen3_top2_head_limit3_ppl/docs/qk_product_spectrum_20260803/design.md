# QK 二阶矩乘积谱：问题与数学定义

## 问题

检验 QKSieve 使用的 QK 联合几何是否集中在少数方向。如果
`M = Cq_tilde^(1/2) Ck^(1/2)` 的奇异值快速衰减，则低维坐标和分层位宽具有数值依据；如果谱平坦，则固定低维压缩会系统性遗漏 score 信息。

## 数学对象

对每层、每个 KV head，使用未中心化二阶矩：

```text
Ck = K^T K / n_k
Cq = Q^T Q / n_q
Cq_tilde = (1 - lambda) Cq + lambda * trace(Cq) / d * I
M = Cq_tilde^(1/2) Ck^(1/2)
sigma = svdvals(M)
```

当前实现使用 `lambda=0.75`。同时计算 `lambda=0`，但后者仅作为采样秩上限对照。

## 可证伪判断

- 若达到 95% 或 99% 的平方奇异值能量需要接近 128 维，则谱不集中。
- 若不同层/头所需秩接近，则统一维度有依据。
- 若不同层/头差异大，则应依据谱尾连续分配维度或 bit，不能统一截断。

本实验只说明 QK score 的二阶几何，不直接证明 attention output 或最终任务质量保持。
