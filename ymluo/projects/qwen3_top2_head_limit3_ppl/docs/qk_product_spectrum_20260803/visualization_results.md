# 4K 谱实验结果

## 结论

在当前真实收缩参数 `lambda=0.75` 下，`M` 的谱明显集中，但不是严格低秩。低维 QK 表征有数值依据；统一固定 16 维没有依据，因为第 0 层和少数 head 的谱明显更平。

## 汇总结果

| 指标，lambda=0.75 | 中位数 | 10%--90% | 最差值 |
|---|---:|---:|---:|
| 前 16 维能量 | 95.02% | 93.00%--96.24% | 81.70% |
| 前 32 维能量 | 97.49% | 96.37%--98.21% | 91.23% |
| 前 48 维能量 | 98.80% | 98.20%--99.20% | 96.39% |
| 前 64 维能量 | 99.48% | 99.22%--99.68% | 98.78% |
| rank95 | 16 | 10--25 | 43 |
| rank99 | 52 | 44--60 | 68 |
| sigma48 / sigma1 | 2.58% | 2.16%--3.18% | 7.41% |
| sigma128 / sigma1 | 0.0079% | 0.00016%--0.0190% | 0.0396% |

## 分层失败样例

第 0 层最不集中：前 16 维平均只有 86.21%，达到 95% 能量平均需要 35.75 维。最差两个 head 分别需要 42 和 43 维达到 95%。相比之下，第 24--29 层通常只需约 11--14 维。

因此，实验支持“按层/头根据谱尾分配维度或 bit”，不支持“所有 head 固定 16 维”。

## 重要限定

`lambda=0` 时每个 KV head 只有 32 个 Query 样本，所以 `rank(Cq) <= 32`，进而 `rank(M) <= 32`。此时前 32 维能量为 100% 是线性代数上的采样秩限制，不是模型天然低秩的证据。可信结论应看当前实际使用的 `lambda=0.75`。

这次实验只有一个 4K sports 请求。它不能证明 64K、128K 或其他主题具有相同谱；下一步若继续，应保持同一文本与 query 口径，扫描长度和主题，而不是直接据此改算法。
