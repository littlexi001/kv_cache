# 结果记录

## 实验设置

本页记录 Llama-3.1-8B-Instruct 的固定目标 PPL 与真实 Q/K/V 机制实验。`local error` 是单个 attention head 的近似输出相对完整 attention 输出的 L2 误差。它不是整模型 PPL，但可用于定位误差发生在哪一层和哪一阶段。

## 已确认结果

### 1. 64K 不是突变点

同一目标 token 从 32K 扩展到 128K 时，exact top-1,280 承载的 attention mass 连续下降。例如 computer 从 94.73% 降到 89.79%，mixed_b 从 95.20% 降到 88.02%，politics 从 92.20% 降到 86.00%。QK proxy 和 sampled threshold 的额外损失明显更小。

允许结论：固定 top-k 的遗漏 softmax 质量是当前主要长度效应。

不能证明：所有模型、所有层都不需要提高 Key 位宽。

### 2. 直接抽样 Value 尾部失败

128K real-QKV 上，rank-16 sketch 的平均局部误差为 6.25%；直接均匀抽样 256 个 tail token 的误差为 20.81%，joint K/V control variate 为 18.24%。score-only 校正为 6.79%。

允许结论：tail partition 已较准确，直接抽样的 Value 方差过大；主要问题是 Value 残差方向。

### 3. 误差集中在少数结构性风险层

rank-16 在 128K 的分层平均局部误差：层 0 为 20.15%，层 8/16/24/31 分别为 2.15%、1.94%、3.46%、3.55%。仅提高层 0 到 rank 128、其他采样层保持 rank 16，五个采样层的平均误差降到 2.18%。

允许结论：统一提高所有层 rank 浪费存储；需要按可测残差风险分配。

不能证明：层 0 在所有模型和请求中永远最危险。

### 4. Key 条件 Value 残差是目前最强的新现象

在 128K computer real-QKV 上，候选集合仍由 QKSieve proxy top-1,280 给出。下表比较同一 rank-16 Value sketch 的尾部估计：

| 方法 | 平均 local error | p90 | p99 | 最大值 |
|---|---:|---:|---:|---:|
| 固定 `alpha=1` | 6.24% | 13.87% | 71.44% | 88.62% |
| 256-token 块残差均值 | 5.78% | 12.33% | 74.28% | 91.20% |
| 块内 Key 条件残差，d=8 | 2.69% | 7.28% | 19.99% | 22.60% |
| 块内 Key 条件残差，d=16 | 2.58% | 7.13% | 19.54% | 21.88% |
| 块内 Key 条件残差，d=32 | **2.48%** | **7.00%** | 20.01% | **21.44%** |

最难的层 0 从 20.47% 降到 8.53%、8.25%、8.07%（proxy 权重口径）。这说明 Value 残差与低维 Key 坐标存在可利用的条件结构，而不只是块内常数。

允许结论：该现象值得进入跨主题、跨模型和整模型 PPL 验证。

不能证明：当前解析回归已经是最终方法；p99 仍约 20%，因此还需要风险触发的 rank 升级。

## 当前失败方向

- 固定 `alpha=0.5`：医学可恢复，但宗教文本会过补偿。
- 直接均匀 tail 采样：Value 方差太大。
- 只存块 Value 均值：时间局部性不足。
- 纯 Cauchy 确定性 QK crossing certificate：候选比例约 45%--49%，证明安全但读取成本过高。

## 下一项决定性实验

1. 在 Llama sports/medicine 32K 和 Qwen3-4B 32K trace 上复测条件残差。
2. 检验回归后风险值是否能捕获 p99 outlier，并冻结一个与长度、任务无关的阈值。
3. 比较固定 rank-16、层 0 rank-128 和风险自适应方法的 128K 整模型 PPL。
4. 质量门槛通过后再实现融合 kernel 和独立测速。
