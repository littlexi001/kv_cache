# 条件矩残差修正：结果

## 实验设置

本页只记录同一候选集合下的 Value 尾部修正。`projected_relative_l2` 是单层所有 attention head 拼接后经过该层 `o_proj` 的输出，与 Full attention 输出之间的 L2 误差，再除以 Full 输出 L2；数值越低越好。它不是最终 PPL，也不是端到端速度。

## 已完成的固定强度筛查

Qwen 的 4K/32K/96K 体育和医学共六个闭环小样本中，完整强度条件修正在四个样本上降低 KL，但在体育 4K 和部分 PPL 比较上出现过修正。当前 Python 原型还会物化 FP32 坐标并全历史扫描，单步约比现有残差均值版本慢 3 至 4 倍，因此不能作为系统速度结果。

允许的结论：Key 坐标与 Value 残差之间存在可利用信号，但固定系数 1.0 不够稳定。

不允许的结论：尚不能声称条件矩全面超过 QKSieve-Robust，也不能使用 Python 原型时间代表融合实现。

## Wiener 收缩结果

结果目录：`results/20260804_conditional_wiener_generality_6gpu_v1`。表中三列误差均为 `projected_relative_l2` 的请求平均值，并换算为百分比；越低越好。`最差配对变化` 是 Wiener 相对残差均值在所有请求中的最大误差增加，负值表示每个请求都更好。

| 模型/主题/长度 | 残差均值 | 固定条件矩 d8 | Wiener d8 | gamma 中位数 | 最差配对变化 |
|---|---:|---:|---:|---:|---:|
| Qwen 体育 32K | 1.3746% | 0.7797% | 0.9969% | 0.3446 | -0.0300 pp |
| Qwen 医学 32K | 0.8628% | 0.5758% | 0.6820% | 0.3994 | -0.0234 pp |
| Qwen 体育 96K | 1.2463% | 0.7869% | 0.8676% | 0.6120 | -0.0249 pp |
| Qwen 医学 96K | 1.6318% | 0.9005% | 1.0426% | 0.6049 | -0.0473 pp |
| Llama 宗教 4K | 6.9987% | 7.3275% | 6.9839% | 0.0036 | +0.0032 pp |
| Llama 计算机 128K | 5.1596% | 2.5981% | 3.6325% | 0.3909 | -1.5271 pp |

固定强度 d8 在 Llama 4K 明显过修正，而 Wiener d8 基本退化为残差均值；在条件信号较强的 Qwen 32K/96K 和 Llama 128K 上，Wiener d8 保留了稳定收益。Qwen 四组共 32/32 个请求均优于残差均值；Llama 4K 为 7/8，唯一退化为 0.0032 个百分点，低于该组请求间变化。

允许的结论：交错留出的解析收缩能区分弱条件信号和强条件信号，明显降低固定强度过修正风险。

仍不允许的结论：这些数据只测真实 Q/K/V 的单层输出。当前剩余不确定性是该收益能否在模型闭环 PPL、KL 和 top-1 一致率上稳定兑现，以及融合 CUDA 实现能否消除 Python 全历史张量开销。
