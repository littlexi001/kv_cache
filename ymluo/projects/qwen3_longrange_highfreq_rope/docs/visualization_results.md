# 实验结果与可视化

## 实验设置

本项目比较同一 Qwen3-8B checkpoint 在原生 RoPE、高频全局删除、高频深层删除和仅远程相位减速下的表现。所有结果必须同时报告 RULER 官方分数、gold NLL 和逐层证据诊断；在结果落盘前不填写结论。

## 当前状态

模型、代码和 RULER-32K 数据已在 `10.176.37.30` 配置完成。固定隐藏状态的 F0–F7 反事实诊断已完成；端到端干预仍在运行。

## 固定隐藏状态结果

实验只做一次原生前向，然后在每层每个 query head 中把 F0–F7 的相对 RoPE 相位替换成零相对相位。这样 Q/K 内容、其他频率、Value 和后续层状态都不变。6 条计划样本中有 5 条能从 prompt token 中精确定位 gold answer；Hotpot 样本没有精确 token occurrence，因此标为证据不足，没有混入均值。

| 深层 L18–L35 指标 | 5 条样本结果 | 如何理解 |
| --- | ---: | --- |
| F0–F7 对 gold logit 的平均相位贡献 | -0.336 logit | 负数说明原生高频相位平均压低 gold token |
| 相位贡献为负的 layer×head 比例 | 64.31% | 抑制现象常见，但不是所有 head 都成立 |
| NoPE 后 gold mass 平均变化 | -0.000401 | gold mass 绝对下降约 0.040 个百分点 |
| NoPE 后 mass 上升的点占比 | 56.81% | 多数点略升，但少数较大下降主导均值 |
| NoPE 后最佳 gold rank 平均变化 | +82.38 名 | 正数更差，背景 token 通常被抬得更多 |
| NoPE 后 rank 改善的点占比 | 32.95% | 只有约三分之一改善 |
| `max pre-RoPE cosine ≥ 0.9` 的比例 | 0% | 文档 A1 的强对齐条件不符合这些真实 Q/K |
| Query 频率能量到均匀模板的平均 L1 | 1.094 | 文档 A2 的近均匀条件也不符合真实 Query |
| F0–F7 的 Query 能量占比 | 3.61% | 均匀模板应为 12.5%，真实模型明显降低了高频能量 |

在按原生 evidence mass 事后选出的深层 top 10% 点中，F0–F7 的平均贡献接近零（-0.035 logit），NoPE 使 gold mass 下降 0.00229，即约 0.229 个百分点。这个子集只是诊断，不能作为无偏任务结果；但它说明真正大量读取 evidence 的 head 并没有表现出更强的高频伤害。

### 当前允许的结论

真实模型中，F0–F7 经常在绝对 logit 上压低证据；然而直接取消相位同时改变所有背景 token，不能由“gold logit 上升”推出“gold 更容易被检索”。目前证据反对简单的全局高频删除，并且显示理论文档中的 A1/A2 是较强的充分条件，不是当前样本的典型经验条件。距离条件方法是否能在端到端任务上改善，仍需等待正在运行的对照。

- 问题：哪一种高频干预改善或损害长程任务？
- 指标：相对 native 的 paired official score，单位为百分点。

### 图 2：证据 QK 高频贡献随距离变化

- 问题：F0–F7 在真实 evidence token 上是帮助还是抑制？
- 指标：`C_H=s-s^{\\setminus H}`，单位为 pre-softmax logit。
- 横轴：Query–evidence 相对距离，token。
- 纵轴：F0–F7 对 evidence logit 的净贡献；负数表示抑制。
- 颜色：layer 或 KV head group，不能在同一轴混入 task score。
- 允许结论：固定当前层隐藏状态下的直接相位作用；不证明端到端因果链。

### 图 3：证据 attention mass 与 rank

- 问题：去除高频后，证据在所有历史 token 的竞争中是否更容易被读取？
- 指标：gold span softmax mass（百分比）和最佳 gold token rank（名次），分成两张图。
- 允许结论：检索阶段改善或退化；不能单独等价为最终答案质量。

## 当前不确定性

已经知道这 5 条样本不满足强 A1/A2。尚不知道距离条件修正能否借助跨层传播提高最终答案，也不知道结论能否扩展到更长距离、多 seed RULER 和 LongBench。
