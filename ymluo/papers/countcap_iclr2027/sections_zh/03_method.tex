\section{\method 方法}
\label{sec:method}

\subsection{问题与 QK-balanced 坐标}

对于映射到 KV head $g(h)$ 的 Query head $h$，稠密 attention 为
\begin{equation}
 s_{h,i}=q_h^\top k_{g(h),i}/\sqrt d,\quad
 p_h=\softmax(s_h),\quad o_h=\sum_i p_{h,i}v_{g(h),i}.
 \label{eq:full-attn}
\end{equation}
我们寻找 Query-dependent 集合 $\widehat S_h$，并在该集合内用原始 K/V 精确
重算\cref{eq:full-attn}。所有历史 token 始终可被访问。

对于每层、每个 KV head，我们以 stride 32 采样 post-RoPE prompt Key，并从
所有映射的 Query head 采集最后八个 prompt Query 位置。未中心化二阶矩为
\begin{equation}
 \widehat C_k=m_k^{-1}\sum_i k_i k_i^\top,\qquad
 \widehat C_q=m_q^{-1}\sum_j q_j q_j^\top .
 \label{eq:qk-moments}
\end{equation}
因为 Query 样本较少，先作固定收缩
\begin{equation}
 S_q=(1-\lambda)\widehat C_q+\lambda\tr(\widehat C_q)I/d,
 \qquad\lambda=.75,
 \label{eq:q-shrink}
\end{equation}
再统一将特征值下限设为 $10^{-8}\lambda_{\max}+10^{-12}$，得到正定矩阵
\begin{equation}
 C_k=\mathcal F(\widehat C_k),\qquad
 \widetilde C_q=\mathcal F(S_q).
 \label{eq:moment-floor}
\end{equation}
估计过程不使用任务标签或训练参数。

令
\begin{equation}
 \widetilde C_q^{1/2}C_k^{1/2}=U\Sigma V^\top
 \label{eq:qk-svd}
\end{equation}
并定义
\begin{equation}
 A=\widetilde C_q^{-1/2}U\Sigma^{1/2},\qquad
 D=C_k^{-1/2}V\Sigma^{1/2}.
 \label{eq:qk-factors}
\end{equation}
对于 $q'=A^\top q$ 与 $k'=D^\top k$，有
\begin{equation}
 AD^\top=I,\qquad {q'}^\top k'=q^\top k,
 \label{eq:qk-exact}
\end{equation}
以及
\begin{equation}
 A^\top\widetilde C_qA=D^\top C_kD=\Sigma.
 \label{eq:qk-covariance}
\end{equation}
因此全维变换本身不产生分数误差，$\Sigma$ 按联合 Query--Key 分数能量而不是
Key 重建能量排序坐标。

\subsection{Query-weighted 混合位宽索引}

当 $d=128$ 时，八个连续的 16 维 band 分别获得
$b_g\in\{0,1,2,4,8\}$ bit/coordinate。每个 active band 还为每个 token 保存
一个 FP16 scale，相当于每维一个 metadata bit，因此
\begin{equation}
 R(b)=16\sum_{g=1}^{8}\bigl(b_g+\1[b_g>0]\bigr)\le240\text{ bits}.
 \label{eq:packed-rate}
\end{equation}
0-bit band 不占物理空间；2/4/8-bit 使用 max-absolute scale，1-bit 使用符号乘
平均绝对值。

令 band 量化误差为 $e_{i,g}(b)=k'_{i,g}-Q_b(k'_{i,g})$，经验 Query 与误差
二阶矩为 $C'_{q,g}$ 和 $C_{e,g}(b)$。Cartesian Query--Key 样本上的分数失真
精确等于
\begin{equation}
 D_g(b)=\frac{1}{m_qm_k}\sum_{j,i}
 ({q'_{j,g}}^\top e_{i,g}(b))^2
 =\tr(C'_{q,g}C_{e,g}(b)).
 \label{eq:band-qmse}
\end{equation}
每层、每个 head 的 allocation 为
\begin{equation}
 b^\star=\arg\min_b\sum_gD_g(b_g)\quad\text{s.t.}\quad R(b)\le240.
 \label{eq:qmse-allocation}
\end{equation}
我们精确枚举很小的可行集合，并在 prefill 后冻结结果。30-byte Key index 对
$d=128$ FP16 K+V 的额外开销为 $30/512=5.86\%$。Key-MSE、固定 4-4-2-1、
Key-PCA 与随机旋转只作为消融；冻结方法使用\cref{eq:qmse-allocation}。

\subsection{Packed selection 与精确 attention}

每个 decode Query 先被变换并量化为 INT8。优化 CUDA 路径从索引中规则分层
采样
\begin{equation}
 m(N)=\min\{N,512,\max(256,\lceil16/(B(N)/N)\rceil)\}
 \label{eq:frozen-quantile-samples}
\end{equation}
个条目以估计目标 quantile，再扫描 packed index 一次，将超过阈值的条目直接
写入有界 buffer。该过程避免长度为 $N$ 的分数张量和通用 top-$k$。参考路径
则物化全部 proxy score 并执行确定性 top-$B(N)$，用于隔离表征误差与阈值估计
误差。

对于选中位置 $\widehat S_h$，原始常驻 FP16 K/V 计算
\begin{equation}
 \widetilde p_{h,i}=\frac{e^{s_{h,i}}}
 {\sum_{j\in\widehat S_h}e^{s_{h,j}}},\qquad
 \widetilde o_h=\sum_{i\in\widehat S_h}\widetilde p_{h,i}v_{g(h),i}.
 \label{eq:sparse-attn}
\end{equation}
因此近似只影响离散选取集合。没有 exact rerank、router、任务规则、
sink/recent 保留或 Full fallback。

\subsection{Robust 遗漏 Value 估计}

即使 Key 排序准确，许多较小的遗漏权重仍可能携带相干的 Value 总贡献。令
$S=\widehat S_h$、$T=[N]\setminus S$，$\widehat\tau$ 为 proxy threshold。
Robust 在同一次扫描中累计
\begin{equation}
 \widehat Z_T=\sum_{i\in T}e^{\widehat s_i-\widehat\tau},\qquad
 \widehat c_T=\sum_{i\in T}e^{\widehat s_i-\widehat\tau}\widehat c_i.
 \label{eq:value-tail-statistics}
\end{equation}
Request-local rank-16 Value PCA 将 $c_i=P_v^\top(v_i-\mu_v)$ 存为
block-256 affine INT4。66 bit/token 的 Value code 使 Key+Value index 总开销为
FP16 K+V 的 7.47\%。记精确 selected numerator、partition 和最大值为
$u_S,Z_S,m$，Robust 返回
\begin{equation}
 \widehat o_\alpha=
 \frac{u_S+\alpha e^{\widehat\tau-m}
 (\widehat Z_T\mu_v+P_v\widehat c_T)}
 {Z_S+\alpha e^{\widehat\tau-m}\widehat Z_T},\qquad\alpha=.5.
 \label{eq:robust-tail-output}
\end{equation}
固定 shrinkage 在注册 weak case 上选择，随后对 held-out seed 冻结。Fast 去掉
该估计器；Robust 是全长度统一的主 consumer，不改变 $B(N)$，也不读取更多
精确 KV。

\subsection{构建与注册配置}

Dense prefill 暴露 prompt-tail Query 后，方法构建 $(A,D)$、$b^\star$、历史
packed Key 与 Value sketch。生成时每个 token 只追加一个 exact K/V 和一个
packed entry，request-local basis 始终冻结。Reference profile 使用完整 proxy
top-$k$；部署 Fast/Robust 使用 sampled-quantile selector。三者共享变换、
allocation、token budget 与精确 K/V。CUDA 路径融合 Query 准备、packed scan、
candidate compaction 和精确稀疏 attention；Robust 再融合 tail 累计与消费。
完整伪代码、quantizer 细节、kernel 等价性检查、状态更新不变量与字节统计见
\cref{app:algorithm,app:repro}。
