\section{理论分析}
\label{sec:analysis}

\paragraph{精确几何。}
代入\cref{eq:qk-svd,eq:qk-factors}可得
\begin{equation}
 AD^\top=I,\qquad
 A^\top\widetilde C_qA=D^\top C_kD=\Sigma,
 \label{eq:main-exact-balance}
\end{equation}
因此未量化变换不改变任何 QK 分数。此外，在秩为 $r$ 的双线性近似中，截断
该 SVD 使期望平方分数误差最小：
\begin{equation}
 \min_{\operatorname{rank}(W)\le r}
 \mathbb E(q^\top k-q^\top Wk)^2=\sum_{j>r}\sigma_j^2.
 \label{eq:main-rank-optimal}
\end{equation}
证明、正则化条件与 Query--Key 相关性残差见\cref{app:proofs}。

\paragraph{为什么使用 Query-weighted allocation。}
对于量化误差 $e=k'-\widehat k'$，经验 Cartesian Query--Key 样本满足
\begin{equation}
 \mathbb E(q'^\top e)^2=\tr(C'_qC_e),
 \label{eq:main-qmse}
\end{equation}
allocator 最小化\cref{eq:band-qmse}中各 band 的对角块之和；当任一二阶矩在
这些 band 上为 block diagonal 时，它等于完整 score MSE。否则遗漏的
cross-band 项由\cref{eq:cross-band-bound}显式约束并审计。Key-MSE
$\tr(C_e)$ 只有在 $C'_q$ 各向同性时才正确。若 decode Query 发生漂移
$\Delta=C'_{q,\mathrm{dec}}-C'_{q,\mathrm{cal}}$，则
\begin{equation}
 |\tr(\Delta C_e)|\le\|\Delta\|_{\op}\tr(C_e).
 \label{eq:main-drift}
\end{equation}
这是稳定性诊断，而非无条件 held-out 保证。有限样本、子空间扰动、allocation
regret 和固定码率条件界见\cref{app:proofs}。

\paragraph{排序与输出。}
令精确与 proxy 分数误差为 $\delta_i=s_i-\widehat s_i$，并记
$R_\delta=\max_i\delta_i-\min_i\delta_i$。任何 boundary margin 大于
$R_\delta$ 的 exact top-$B$ token 都仍会被选中。附录进一步将 centered score
RMSE 转换为 preserved-core 与遗漏 mass certificate。对实际选中集合 $S$，令
$\epsilon=\sum_{i\notin S}p_i$，在 $S$ 上精确重算可得
\begin{equation}
 \|p-\widetilde p\|_1=2\epsilon,
 \qquad\|o-\widetilde o\|_2\le\epsilon\,\diam\{v_i\}.
 \label{eq:main-output-bound}
\end{equation}
因此 selector 质量取决于 score margin 和遗漏概率质量，而不仅是集合召回率。

\paragraph{Robust 修正什么。}
记 exact selected/omitted conditional Value mean 为 $\mu_S,\mu_T$，selected
mass 为 $p$，Robust 估计为 $\widehat p,\widehat\mu_T$。其输出误差精确分解为
\begin{equation}
 \widehat o_\alpha-o=(\widehat p-p)(\mu_S-\mu_T)
 +(1-\widehat p)(\widehat\mu_T-\mu_T),
 \label{eq:tail-error-decomposition}
\end{equation}
从而
\begin{equation}
 \|\widehat o_\alpha-o\|_2\le
 |\widehat p-p|\|\mu_S-\mu_T\|_2
 +(1-\widehat p)\|\widehat\mu_T-\mu_T\|_2.
 \label{eq:tail-error-bound}
\end{equation}
若 tail-estimation error 为零均值、方差为 $V$，且
$D=\|\mu_S-\mu_T\|_2^2$，tail mixture weight $w_\alpha$ 的风险为
\begin{equation}
 \mathbb E\|\widehat o_\alpha-o\|_2^2
 =((1-p)-w_\alpha)^2D+w_\alpha^2V,
 \label{eq:tail-bias-variance}
\end{equation}
它优于 Fast 的充要条件为
\begin{equation}
 0<w_\alpha<2(1-p)D/(D+V).
 \label{eq:tail-correction-benefit}
\end{equation}
因此 Robust 修正的是单纯改善 Key top-$k$ 无法消除的遗漏 Value 误差，但固定
shrinkage 仍必须经过 held-out 检验。

\paragraph{成本与 crossover。}
两个配置都扫描 $\Theta(N)$ 个低位条目；精确 attention 由
\cref{eq:budget-intro}限制。Robust 额外扫描 66 Value bits/token。若
$f_t,s_t$ 是直接测量的 Full/QKSieve 每步成本，$I_{\rm net}$ 是未隐藏的构建
成本，则生成 $G$ 个 token 后达到 break-even 当且仅当
\begin{equation}
 \sum_{t=1}^{G}(f_t-s_t)>I_{\rm net}.
 \label{eq:main-break-even}
\end{equation}
若 Full 的非 attention 与 attention 成本分别为
$t_{\rm base},t_{\rm attn}$，整模型理论上限为
\begin{equation}
 \mathrm{speedup}\le(t_{\rm base}+t_{\rm attn})/t_{\rm base}.
 \label{eq:main-amdahl}
\end{equation}
因此本文分别报告 cold、warm 与 persistent reuse。
