\section{引言}
\label{sec:introduction}

长上下文解码在生成每个 token 时都要重新读取不断增长的键值（KV）历史。
KV eviction 通过永久丢弃状态来降低成本
\citep{zhang2023h2o,li2024snapkv,cai2024pyramidkv,feng2024adakv}；
Query-aware retrieval 则保留全部状态，并在每一步重新选择子集
\citep{ribar2023sparq,tang2024quest,singhania2024loki}。只有当选择子集的成本
显著低于被省去的稠密 attention 时，检索才真正有价值。

低位 token 索引是一条直接路径：近似所有 QK 分数、选择 top-$k$，再对原始
K/V 执行精确 attention。FIER 表明 1-bit Key 也能保留有用的排序
\citep{wang2025fier}，但统一 Key quantizer 最小化的是重建误差，而 attention
实际观察的是 $(q^\top k-q^\top\widehat k)^2$。两者只有在 Query 各向同性时才
一致。因此本文研究：\emph{在固定索引字节预算下，如何依据 Query--Key 联合
几何来分配表征能力？}

我们提出 \method：一种无需训练、精确 KV 常驻 GPU 的检索方法。对每层、每个
KV head，prompt 样本定义两个 request-local 线性变换。它们是双正交的：量化
前精确保持每个点积，同时使变换后的 Query 与 Key 二阶矩等于同一个对角联合
能量谱。\method 将 128 个坐标分成八个 16 维 band，并在
240 bit/token/head 预算下精确求解 0/1/2/4/8-bit allocation，使经验
attention-logit MSE 最小。Key index 额外占 FP16 K+V 的 5.86\%。

每一步 decode 中，packed scan 为每个 Query head 选择
\begin{equation}
 B(N)=\min\{N,1280,\max(256,\lceil0.06N\rceil)\},
 \label{eq:budget-intro}
\end{equation}
个位置。Sampled-quantile kernel 不物化长度为 $N$ 的分数向量，也不调用通用
top-$k$；随后原始 FP16 K/V 执行精确稀疏 QK--softmax--AV。整个方法没有
学习式 router、任务规则、精确 QK 重排、受保护 token 启发式或 Full 回退。

即使选取排序准确，许多单独很小的遗漏权重仍可能携带相干的 Value 总贡献。
冻结的 QKSieve-Robust consumer 因此在同一次扫描中估计遗漏 partition 和当前
Query 条件下的 rank-16 INT4 Value 残差，总辅助开销为 7.47\%。
QKSieve-Fast 去掉该残差，作为质量/成本的因果消融；主方法不在人工长度边界
切换配置。完整流程见\cref{fig:overview}。

本文贡献如下：
\begin{itemize}
  \item 推导精确保持点积、显式暴露联合分数能量谱的全秩 QK-balanced 坐标，
  并将 per-head 混合位宽索引写成硬件可见的 rate-distortion 问题。
  \item 实现 GQA/MHA packed sampled-quantile selector 和精确稀疏 attention，
  并提出针对弥散遗漏 mass 的显式低秩 Value-tail 修正。
  \item 通过精确分解、logit-MSE、margin、遗漏 mass 与 residual bound，将量化
  误差连接到排序和最终输出误差。
  \item 系统评测检索质量、完整 LongBench、原生 128K 压力案例、同路径 FIER、
  直接计时的 attention/decode，以及 persistent-cache 的 cold、warm、
  shared-prefix 和 append-only 场景。冻结 Robust 在 128K PPL 上保持
  99.805\%，并在 8K--128K 原生 MHA attention 上达到
  1.08--4.12$\times$。
\end{itemize}
