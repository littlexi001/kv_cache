\section{相关工作}
\label{sec:related}

\paragraph{KV 缩减。}
H$_2$O、SnapKV、PyramidKV 与 Ada-KV 通过驱逐 token 或在层/head 间分配保留
预算来降低物理 cache 大小
\citep{zhang2023h2o,li2024snapkv,cai2024pyramidkv,feng2024adakv}；KIVI
量化保留的 KV \citep{liu2024kivi}。\method 保留全部精确 KV 并增加检索索引，
目标是减少 decode attention，而不是缩小精确 cache。

\paragraph{Query-aware 稀疏 attention。}
Quest 用 Key 统计量剪枝 page \citep{tang2024quest}；SparQ 用显著 Query 维度
检索，并以 mean Value 修正遗漏概率质量 \citep{ribar2023sparq}；Loki、
ShadowKV、LRQK、SALS、RocketKV 与 Thin Keys 利用低维 Key/QK 结构
\citep{singhania2024loki,sun2024shadowkv,li2025lrqk,mu2025sals,
behnam2025rocketkv,yao2026thinkeys}。RetrievalAttention 与 RetroInfer 将近似
检索和 offloaded exact KV 结合
\citep{liu2024retrievalattention,chen2025retroinfer}。这类异构系统面向不同的
KV 放置场景；本文主协议保持 exact KV 常驻，并测量 selector 加精确稀疏
attention 的完整路径。

\paragraph{低位 selector。}
FIER 扫描 1-bit token-level Key，再对选中 KV 执行精确 attention
\citep{wang2025fier}。RaBitQCache 与 Self-Indexing KVCache 使用 binary code
\citep{li2026rabitqcache,yang2026selfindexing}；SVDq 在 SVD 空间分配混合精度
\citep{hong2025svdq}；BinaryPC 学习 binary principal component，并在 GQA
组内共享候选 \citep{yu2026binarypc}。Block-GTQ 在压缩 K/V cache 的固定 RoPE
block 上分配精度 \citep{liang2026blockgtq}。\method 的区别是三个耦合设计：
Query/Key 全秩变换联合构造且精确双正交；bit 根据 Query-weighted logit
distortion 按层/head 分配；低位表征只索引独立的精确 K/V。因此，等索引率和
等 active-token 对照能够单独比较 selector，而不混入 KV 量化或放置差异。

\paragraph{残差近似与评测。}
RESA 从 prefill-derived 低秩先验估计遗漏 attention \citep{yang2026resa}。
QKSieve-Robust 则使用当前 Query 的 proxy 分数，同时估计遗漏 softmax
partition 和 request-local Value basis 中的系数，不需要学习式先验。
LongBench 测量异构长上下文生成，RULER 测量不同长度下的受控检索
\citep{bai2024longbench,hsieh2024ruler}。本文将下游质量、索引字节、active KV、
attention latency、整模型 decode，以及 cold/persistent request 成本分别报告；
不同模型、kernel 或 KV 放置的数值不作为直接速度比较。
