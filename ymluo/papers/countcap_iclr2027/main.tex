\begin{abstract}
Autoregressive decoding repeatedly scans an increasingly long key--value
(KV) history.  Token-level sparse attention can avoid most exact attention,
but only if its retrieval index is both cheaper than full QK scoring and
faithful to the query-dependent score geometry.
We present \method, a training-free, GPU-resident exact-KV retrieval
accelerator.
For every layer and KV head, query and key second moments define a
biorthogonal coordinate system that preserves every uncompressed dot product
exactly and orders coordinates by joint score energy.
\method partitions the 128 transformed coordinates into eight 16-D bands and
assigns each band 0/1/2/4/8 bits under a fixed 240-bit token/head index
budget.  The reference allocator minimizes empirical attention-logit MSE;
the frozen main path uses the same request-local query-weighted MSE objective;
Key-MSE is retained as a deployment ablation.
A packed scan selects a length-dependent budget $B(N)$ per query head,
followed by exact sparse QK--softmax--AV over the original FP16 KV; the
registered experiments through 128K cap $B(N)$ at 1,280.
The method has no learned router, task rule, exact-QK reranking, or
full-attention fallback.
We audit two registered profiles built from the same request-local transform
and allocation: a reference using complete proxy top-$k$, and an optimized
profile using fused Query preparation, architecture-specific GQA/MHA scanning, and a
capped sampled quantile that avoids score materialization and generic top-$k$.
The Fast profile adds 5.86\% to the FP16 K+V footprint.  A Robust profile
adds a rank-16 INT4 Value-tail sketch for a total 7.47\%; the exact KV itself
remains GPU resident in both profiles.
Robust is frozen as the paper's length-agnostic main consumer; Fast is a
selected-only ablation.  We do not switch methods at a hand-set context length.
At 1\% active KV, a held-out equal-rate retrieval audit improves exact
top-$k$ recall from 43.36\% to 73.44\% and selected attention mass from
76.40\% to 83.48\% relative to a faithful FIER-1b-g32 reproduction, despite
using a slightly smaller index.
In a controlled six-topic 32K Key-MSE ablation, QK-balanced
coordinates reduce KL from .0211 to .0084 over Key-PCA; the paired NLL
advantage has a 95\% interval of [.0008, .0189].
On the complete 3,750-example, 16-task Llama-3.1-8B LongBench evaluation,
\method's reference profile retains 99.88\% of the Full-attention macro
score, with a paired bootstrap 95\% interval of [99.42\%, 100.35\%].
A strict 160-example same-path screen evaluates an earlier length-gated
Fast/Robust ablation: it scores .453676 versus
.453019 for Full and retains 100.145\%, with a paired-sample bootstrap
interval of [97.915\%, 102.051\%].
At the native 128K boundary, the Fast profile exposes a real failure mode:
six topic/seed cases retain only 96.32\% pooled PPL quality and fall to
91.10\% in the worst case.  The Robust profile estimates the omitted
softmax partition and a current-Query-weighted low-rank Value residual, then
shrinks that residual by $\alpha=.5$.  Across 12 topic/seed cases, including
six held-out seeds, it retains 99.805\% pooled PPL quality with a
case-bootstrap interval of [99.100\%, 100.499\%] and a 96.98\% worst case.
On an 80-example, 16-task same-sample LongBench screen, always-on Robust
retains 98.92\%, whereas the earlier length-gated ablation retains
101.47\% with a paired interval of [99.25\%, 104.45\%].  We retain this as a
failure diagnostic, not as the main method, and require a complete frozen-
Robust LongBench evaluation before final submission.
On native 32-query/32-KV-head MHA with resident FP16 K/V, directly timed
complete attention calls reach 1.27--6.37$\times$ for Fast and
1.08--4.12$\times$ for Robust from 8K to 128K on RTX~3090.  These calls
include Query preparation, low-bit scanning, candidate compaction, exact
sparse attention, and, for Robust, the Value-tail scan and consumer.  In a
real MHA 7B model, steady whole-model decode reaches 1.32/2.22/3.98$\times$
for Robust at 32/64/128K; including one-time construction in a 64-token cold
request gives .81/1.31/2.15$\times$.  We report cold, steady, and persistent
reuse regimes separately.
The same-path screen closes the execution-path mismatch at screening scale,
but its uncertainty does not replace a full deployment-profile evaluation;
we therefore keep the 3,750-example reference claim separate from deployment
speed.
We derive the exact factorization, transformed covariance identity,
query-weighted quantization objective, ranking conditions, and
omitted-attention-mass output bound, and we report all index construction and
selection overhead with direct measurements rather than latency decomposition.
\end{abstract}
