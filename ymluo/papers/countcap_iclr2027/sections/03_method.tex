\section{\method}
\label{sec:method}

\subsection{Problem and QK-balanced coordinates}

For Query head $h$ mapped to KV head $g(h)$, dense attention is
\begin{equation}
 s_{h,i}=q_h^\top k_{g(h),i}/\sqrt d,\quad
 p_h=\softmax(s_h),\quad o_h=\sum_i p_{h,i}v_{g(h),i}.
 \label{eq:full-attn}
\end{equation}
We seek a Query-dependent set $\widehat S_h$ and recompute
\cref{eq:full-attn} exactly on original K/V restricted to that set.  Every
historical token remains addressable.

For each layer and KV head, we sample post-RoPE prompt Keys at stride 32 and
the final eight prompt Query positions from all mapped Query heads.  Their
uncentered second moments are
\begin{equation}
 \widehat C_k=m_k^{-1}\sum_i k_i k_i^\top,\qquad
 \widehat C_q=m_q^{-1}\sum_j q_j q_j^\top .
 \label{eq:qk-moments}
\end{equation}
We shrink the smaller Query sample,
\begin{equation}
 S_q=(1-\lambda)\widehat C_q+\lambda\tr(\widehat C_q)I/d,
 \qquad\lambda=.75,
 \label{eq:q-shrink}
\end{equation}
and consistently floor eigenvalues at
$10^{-8}\lambda_{\max}+10^{-12}$ to obtain positive-definite
$C_k$ and $\widetilde C_q$:
\begin{equation}
 C_k=\mathcal F(\widehat C_k),\qquad
 \widetilde C_q=\mathcal F(S_q).
 \label{eq:moment-floor}
\end{equation}
No task label or trained parameter enters these estimates.

Let
\begin{equation}
 \widetilde C_q^{1/2}C_k^{1/2}=U\Sigma V^\top
 \label{eq:qk-svd}
\end{equation}
and define
\begin{equation}
 A=\widetilde C_q^{-1/2}U\Sigma^{1/2},\qquad
 D=C_k^{-1/2}V\Sigma^{1/2}.
 \label{eq:qk-factors}
\end{equation}
For $q'=A^\top q$ and $k'=D^\top k$,
\begin{equation}
 AD^\top=I,\qquad {q'}^\top k'=q^\top k,
 \label{eq:qk-exact}
\end{equation}
while
\begin{equation}
 A^\top\widetilde C_qA=D^\top C_kD=\Sigma.
 \label{eq:qk-covariance}
\end{equation}
Thus the full transform has zero score error, and $\Sigma$ orders coordinates
by joint Query--Key score energy rather than Key reconstruction energy.

\subsection{Query-weighted mixed-bit index}

For $d=128$, eight contiguous 16-D bands receive
$b_g\in\{0,1,2,4,8\}$ bits per coefficient.  An active band stores one FP16
scale per token, equivalent to one metadata bit per coefficient, giving
\begin{equation}
 R(b)=16\sum_{g=1}^{8}\bigl(b_g+\1[b_g>0]\bigr)\le240\text{ bits}.
 \label{eq:packed-rate}
\end{equation}
Zero-bit bands are physically absent.  The selected symmetric quantizers use
max-absolute scale for 2/4/8 bits and sign times mean magnitude at 1 bit.

For band error $e_{i,g}(b)=k'_{i,g}-Q_b(k'_{i,g})$, define empirical Query
and error moments $C'_{q,g}$ and $C_{e,g}(b)$.  The Cartesian-sample score
distortion is exactly
\begin{equation}
 D_g(b)=\frac{1}{m_qm_k}\sum_{j,i}
 ({q'_{j,g}}^\top e_{i,g}(b))^2
 =\tr(C'_{q,g}C_{e,g}(b)).
 \label{eq:band-qmse}
\end{equation}
The per-layer/head allocation is
\begin{equation}
 b^\star=\arg\min_b\sum_gD_g(b_g)\quad\text{s.t.}\quad R(b)\le240.
 \label{eq:qmse-allocation}
\end{equation}
We enumerate the small feasible set exactly and freeze the result after
prefill.  The 30-byte Key index adds $30/512=5.86\%$ to FP16 K+V for
$d=128$.  Key-MSE, fixed 4-4-2-1, Key-PCA, and random rotations are ablations;
the frozen method uses \cref{eq:qmse-allocation}.

\subsection{Packed selection and exact attention}

Each decode Query is transformed and INT8-quantized.  The optimized CUDA
path samples
\begin{equation}
 m(N)=\min\{N,512,\max(256,\lceil16/(B(N)/N)\rceil)\}
 \label{eq:frozen-quantile-samples}
\end{equation}
regularly stratified index entries, estimates the target quantile, and scans
the packed index once while writing scores above threshold into a bounded
buffer.  This avoids an $N$-length score tensor and generic top-$k$.  The
reference path instead materializes proxy scores and applies deterministic
top-$B(N)$; it isolates representation error from threshold estimation.

For selected positions $\widehat S_h$, original resident FP16 K/V compute
\begin{equation}
 \widetilde p_{h,i}=\frac{e^{s_{h,i}}}
 {\sum_{j\in\widehat S_h}e^{s_{h,j}}},\qquad
 \widetilde o_h=\sum_{i\in\widehat S_h}\widetilde p_{h,i}v_{g(h),i}.
 \label{eq:sparse-attn}
\end{equation}
Approximation therefore changes only the selected set.  There is no exact
rerank, router, task rule, sink/recent reservation, or Full fallback.

\subsection{Robust omitted-Value estimator}

Accurate ranking does not recover a coherent aggregate carried by many
small omitted weights.  Let $S=\widehat S_h$, $T=[N]\setminus S$, and
$\widehat\tau$ be the proxy threshold.  During the same scan, Robust records
\begin{equation}
 \widehat Z_T=\sum_{i\in T}e^{\widehat s_i-\widehat\tau},\qquad
 \widehat c_T=\sum_{i\in T}e^{\widehat s_i-\widehat\tau}\widehat c_i.
 \label{eq:value-tail-statistics}
\end{equation}
A request-local rank-16 PCA of stratified Values stores
$c_i=P_v^\top(v_i-\mu_v)$ as block-256 affine INT4.  Its 66 bits/token make
the total Key-plus-Value index 7.47\% of FP16 K+V.  With exact selected
numerator $u_S$, partition $Z_S$, and maximum $m$, Robust returns
\begin{equation}
 \widehat o_\alpha=
 \frac{u_S+\alpha e^{\widehat\tau-m}
 (\widehat Z_T\mu_v+P_v\widehat c_T)}
 {Z_S+\alpha e^{\widehat\tau-m}\widehat Z_T},\qquad\alpha=.5.
 \label{eq:robust-tail-output}
\end{equation}
The fixed shrinkage was selected on registered weak cases and then frozen for
held-out seeds.  Fast omits this estimator; Robust is the length-agnostic main
consumer and never changes $B(N)$ or reads additional exact KV.

\subsection{Construction and registered profiles}

After dense prefill exposes prompt-tail Queries, the method builds $(A,D)$,
$b^\star$, packed historical Keys, and the Value sketch.  Generation appends
one exact K/V and one packed entry per token while keeping the request-local
basis fixed.  The reference profile uses complete proxy top-$k$; the deployed
Fast and Robust profiles use the sampled-quantile selector.  All share the
same transform, allocation, token budget, and exact K/V.  CUDA paths fuse
Query preparation, packed scanning, candidate compaction, and exact sparse
attention; Robust additionally fuses tail accumulation and consumption.
Full pseudocode, quantizer details, kernel-equivalence checks, state-update
invariants, and byte accounting are in \cref{app:algorithm,app:repro}.
