\section{Related Work}
\label{sec:related}

\paragraph{KV reduction.}
H$_2$O, SnapKV, PyramidKV, and Ada-KV reduce physical cache size by evicting
tokens or allocating retention budgets across layers and heads
\citep{zhang2023h2o,li2024snapkv,cai2024pyramidkv,feng2024adakv}; KIVI
quantizes retained KV \citep{liu2024kivi}.  \method instead keeps every
exact KV pair and adds a retrieval index, targeting decode-time attention
rather than cache capacity.

\paragraph{Query-aware sparse attention.}
Quest prunes pages using Key statistics \citep{tang2024quest}; SparQ retrieves
with salient Query dimensions and corrects omitted probability mass with a
mean Value \citep{ribar2023sparq}; Loki, ShadowKV, LRQK, SALS, RocketKV, and
Thin Keys exploit low-dimensional Key or QK structure
\citep{singhania2024loki,sun2024shadowkv,li2025lrqk,mu2025sals,
behnam2025rocketkv,yao2026thinkeys}.  RetrievalAttention and RetroInfer couple
approximate retrieval with offloaded exact KV
\citep{liu2024retrievalattention,chen2025retroinfer}.  These heterogeneous
systems address a different placement regime; our main contract keeps exact
KV resident and measures selection plus exact sparse attention.

\paragraph{Low-bit selectors.}
FIER scans 1-bit token-level Keys and applies exact attention to selected KV
\citep{wang2025fier}.  RaBitQCache and Self-Indexing KVCache use binary codes
\citep{li2026rabitqcache,yang2026selfindexing}; SVDq assigns mixed precision
in an SVD space \citep{hong2025svdq}; BinaryPC learns binary principal
components and shares candidates within GQA groups \citep{yu2026binarypc}.
Block-GTQ allocates precision to fixed RoPE blocks in a compressed K/V cache
\citep{liang2026blockgtq}.  \method is distinct in three coupled choices:
full-rank Query and Key transforms are jointly constructed and exactly
biorthogonal, bits are allocated per layer/head using Query-weighted logit
distortion, and the low-bit representation indexes separate exact K/V.
Equal-rate and same-active-token controls therefore isolate the selector
rather than conflate it with KV quantization or placement.

\paragraph{Residual approximation and evaluation.}
RESA estimates omitted attention from a prefill-derived low-rank prior
\citep{yang2026resa}.  QKSieve-Robust instead uses current-Query proxy scores
to estimate both the omitted softmax partition and coefficients in a
request-local Value basis, with fixed shrinkage and no learned prior.
LongBench evaluates heterogeneous generation and RULER controlled retrieval
across lengths \citep{bai2024longbench,hsieh2024ruler}.  We keep downstream
quality, index bytes, active KV, attention latency, whole-model decode, and
cold versus persistent request costs separate; numbers from incompatible
models, kernels, or KV placement are not treated as direct speed comparisons.
