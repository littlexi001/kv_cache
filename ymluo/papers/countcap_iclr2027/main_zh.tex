\begin{abstract}
自回归解码会反复扫描完整的键值（KV）历史。Query-aware 稀疏注意力只有在
selector 明显便宜于稠密 QK 打分、同时忠实保持 Query--Key 联合几何时，才能
真正减少计算。本文提出 \method：一种无需训练、精确 KV 常驻 GPU 的检索
方法。每一层、每个 KV head 的 request-local Query 与 Key 二阶矩共同定义一组
双正交坐标；它精确保持所有未量化点积，并按联合分数能量排列维度。随后，
per-layer/per-head allocator 在 240 bit/token/head 预算下，为八个 16 维 band
分配 0/1/2/4/8 bit，并精确最小化可分的 bandwise logit-MSE surrogate。
Packed index 为每个
Query head 选择
$B(N)=\min\{N,1280,\max(256,\lceil.06N\rceil)\}$ 个位置，再对原始 FP16 K/V
执行精确稀疏 attention。方法不使用学习式 router、精确 QK 重排、任务规则或
稠密回退。

Selected-only Fast 配置增加 5.86\% 的 FP16 K+V 存储；冻结的 Robust 主配置
额外加入当前 Query 条件下的 rank-16 INT4 Value-tail 估计，总辅助开销为
7.47\%。在 1\% active KV 下，QK 平衡将等预算 FIER 复现的精确 top-$k$
召回率从 43.36\% 提高到 73.44\%，selected attention mass 从 76.40\% 提高到
83.48\%。完整的 3,750 样本 Llama-3.1-8B LongBench 参考评测保持 Full
宏平均分数的 99.88\%。在 12 个原生 128K 主题/seed case 上，Robust 的 pooled
PPL 质量保持率为 99.805\%，而 Fast 为 96.319\%。

在 RTX 3090 上直接计时的原生 MHA attention 完整路径（包含检索与精确稀疏
attention）中，Robust 在 8K--128K 达到 1.08--4.12$\times$；真实整模型稳态
decode 在 32/64/128K 达到 1.32/2.22/3.98$\times$。Persistent-cache 实验将
cold build 与复用成本分别报告。本文进一步给出分数保持、rate-distortion、
排序稳定和遗漏 mass 的理论界，并只报告直接测量的完整路径时间。
\end{abstract}
