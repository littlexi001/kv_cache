\begin{abstract}
长上下文窗口能够向语言模型提供更多信息，却不能保证语义相关的证据获得更高的检索优先级。
本文研究一种受控失效现象：证据与查询的内容保持不变，只改变二者之间的距离。
在经过位置扩展的 Qwen3-8B 上，仅增加 64 个填充 token，就能使正确首答案 token 的概率从
42.62\% 降至 1.75\%。我们从第一层注意力一直追踪这一失效过程至最终输出。对于固定的
pre-RoPE 查询--键对，post-RoPE 分数是相对距离上多个正弦项之和；我们的精确分解能够重构
实测的第一层分数，最大绝对误差仅为 $1.98\times10^{-3}$。由此产生的注意力扰动进入残差流，
在层间逐步放大并改变答案 margin；只需在第 16 层进行激活修补，便足以逆转原先的错误决策。
这一分析启发了 \method：局部结构和最终注意力计算仍保留标准 RoPE，但在稀疏 softmax 之前，
使用不含位置的 pre-RoPE 分数提出远程候选。在一个 held-out 受控两跳检索测试集上，每个长度
包含 24 个 seed、上下文长度为 8K--64K、候选预算约为 2\%。其中，保守的 \methodpost 变体
将全注意力下的汇总几何平均 \GoldPPL 从 10.851 降至 4.859，并将首 token 准确率从 33.3\%
提高到 47.9\%。在 16K 和 32K 上，它相较精确 post-RoPE Top-2\% 选择也显著改善了配对 NLL；
64K 的置信区间则跨过零点。这些结果在受控检索场景中建立了一条机制解释和针对性修复路径，
但尚不能被视为通用的长上下文解决方案：自然任务、更多模型架构和近似检索索引仍有待验证。
\end{abstract}
